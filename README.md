## 🔭 Focus

- **AI 应用与知识体验**：可溯源的知识助手，答案连接原文，资料不足时说清边界
- **Agent 与人机协作**：AI 拆解目标、提出计划，关键步骤交给人确认，过程透明可控
- **产品验证与迭代**：用真实任务定义"好用"，从有用、可信、易用三个维度做体验评测
- **AI 产品拆解**：体验、定位、商业模式、Agent 架构、模型成本与壁垒放进同一套证据框架
